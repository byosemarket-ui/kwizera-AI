# Product Intelligence Runtime

This runtime creates one persisted digital product profile per Creative Workspace project. It groups uploaded product views and derives classification, brand, materials, colours, texture, shape, features, functions, quality, relationships, history, cache, and analytics from workspace evidence.

The current local analyzers are deterministic metadata and filename rules. Findings that require pixel-level inspection are explicitly marked for visual-provider verification, keeping the public profile contract ready for a future vision inference adapter.
