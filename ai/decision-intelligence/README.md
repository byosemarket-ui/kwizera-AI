# Decision Intelligence Runtime

This project-facing runtime records deterministic, evidence-weighted decisions before pipeline work begins. It compares workflow and creative options, scores them against persisted Product, Image, and Marketing Intelligence, recommends a resource-compatible locally managed model, evaluates bounded risks, and keeps explanations, history, analytics, and cache state.

It is a decision-support layer, not a replacement for the existing AI Core Decision Engine, workflow engine, task manager, automation, generation, rendering, or export systems. Recommendations describe local profile and metadata evidence; they do not claim external performance forecasting.
