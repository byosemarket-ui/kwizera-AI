# Marketing Intelligence Runtime

This runtime produces one persisted marketing strategy profile per Creative Workspace project. It combines workspace audience, brand, campaign, platform, product information, persisted product profiles, and image profiles to record selling points, positioning, CTA options, platform guidance, competitor-safe category benchmarks, recommendations, marketing score, analytics, history, and cache state.

The local implementation provides deterministic strategy guidance from available project evidence. It does not claim live market data, competitor monitoring, or performance prediction from external datasets; those capabilities can be provided later without changing this profile contract.
